Proyectos

Detección de objetos aplicada al rugby – Visión por Computadora

Un modelo de visión por computadora que detecta jugadores, balón y árbitros a partir de vídeos de partidos. El dataset se construyó a partir de fotogramas extraídos y anotados manualmente en Roboflow, con un modelo YOLOv8 entrenado mediante transfer learning y un trabajo iterativo sobre problemas comunes del área (desequilibrio de clases, errores de anotación).

  • YOLOv8
  • Ultralytics
  • Roboflow
  • Transfer learning
  • Visión por computadora

El modelo sigue en desarrollo, sobre todo en la detección del balón.

Plataforma de análisis de datos de fútbol – Ligue 1

Una plataforma que centraliza datos de partidos multi-fuente (eventos, calendario, mercado de fichajes) mediante un pipeline ETL con modelado relacional en PostgreSQL (Supabase). Modelos de Machine Learning (xG, xA, detección de estilo de juego) alimentan una aplicación web interactiva multipágina, desplegada con CI/CD.

  • Python
  • PostgreSQL
  • Supabase
  • Streamlit
  • Machine Learning
  • CI/CD

Agente de IA para cualificación de leads

Un agente impulsado por IA que extrae información estructurada sobre leads y les asigna una puntuación de cualificación. Integra APIs de LLM, n8n, Airtable y Cal.com para automatizar la derivación y el seguimiento, con mecanismos de validación y revisión humana para los casos inciertos.

Para la v2, estoy trabajando actualmente en una capa RAG para que el agente pueda responder preguntas específicas sobre servicios, precios y proyectos anteriores, no solo cualificar y derivar leads.

  • APIs de LLM
  • n8n
  • Airtable
  • Cal.com
  • Automatización
