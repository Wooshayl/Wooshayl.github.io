Détection d'objets appliquée au rugby – Computer Vision

Un modèle de computer vision qui détecte les joueurs, le ballon et les arbitres à partir de vidéos de matchs. Dataset constitué par extraction d'images annotées sur Roboflow, modèle YOLOv8 entraîné par transfer learning, avec un travail itératif sur les erreurs classiques du domaine (déséquilibre des classes, erreurs d'annotation).

  • YOLOv8
  • Ultralytics
  • Roboflow
  • Transfer learning
  • Computer vision

Plateforme de data analytics football – Ligue 1

Une plateforme qui centralise des données de matchs multi-sources (événements, calendrier, marché des transferts) via un pipeline ETL avec modélisation relationnelle sur PostgreSQL (Supabase). Des modèles de Machine Learning (xG, xA, détection de style de jeu) alimentent une application web interactive multi-pages, déployée avec CI/CD.

  • Python
  • PostgreSQL
  • Supabase
  • Streamlit
  • Machine Learning
  • CI/CD
